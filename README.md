# 🎤 PitchPerfect AI – Complete Project Overview

> Empowering users to craft, analyze, and perfect their pitches using cutting-edge AI technology.

---

## 🧩 Project Structure

PitchPerfect AI is divided into two core parts:

- **[`frontend/`](./frontend/)** – React + Vite-powered UI for creating, editing, and receiving real-time feedback on pitch decks.
- **[`backend/`](./backend/)** – Node.js API with AI-powered analysis, OCR, PDF/PPT/image support, and mock investor simulations.

## 🚀 How to Get Started

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-org-or-username/PitchPerfect-AI.git
   cd PitchPerfect-AI
   ```

2. **Navigate to the Desired Component**
   ```bash
   cd frontend   # For frontend setup
   cd backend    # For backend setup
   ```

3. **Follow the setup instructions in the respective README files.**
